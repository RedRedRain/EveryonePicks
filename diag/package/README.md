Private diagnostic logger for working out why a round sometimes stops progressing for one player.

It does not change the game. It only watches and writes a file.

Install it the same way as any other mod, play until the problem happens, then send the newest
file from:

    BepInEx\EPDiag\

One file is written per launch and named with the date and time, so restarting the game never
overwrites an old one. Delete the mod once we are done.
